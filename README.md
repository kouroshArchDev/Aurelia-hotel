# Aurelia Hotel

A modern and responsive hotel website designed and developed as a frontend web development portfolio project.

## Live Demo

Coming soon.

## Overview

Aurelia Hotel is a complete hotel website concept focused on providing a clean, elegant, and user-friendly digital experience.

The website includes hotel information, room discovery, room details, dining and experiences, booking flows, user accounts, and dashboard functionality.

## Features

- Modern and responsive hotel website
- Clean and elegant user interface
- Responsive design for desktop, tablet, and mobile
- Hotel homepage
- Room listing
- Detailed room pages
- Dining section
- Hotel experiences section
- Booking flow
- Booking confirmation
- User login and signup
- User profile
- User settings
- Favorites
- Booking dashboard
- Search history
- Contact and about pages
- Interactive elements with JavaScript

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Git & GitHub
- Vercel
